Quick Start

From download to playing FS25.

1. Install or extract

Use either the per-user Windows installer or the self-contained portable ZIP. Both expose the same Community Preview feature set and do not require a separate .NET installation.

2. Check Home first

Confirm Farm Sim Manager has found the correct FS25 user-data folder, gameSettings.xml, active mods directory and detected saves. Fix discovery here before creating profiles.

3. Launch the current setup — or register mod folders

Beta 2 adds Launch FS25 on Home. Use it when you simply want to start Farming Simulator 25 with the configuration and mod folder that are already active. It does not require a savegame or managed profile and does not switch the active mod collection.

For managed mod collections, open Mods. Use Register active folder for the collection FS25 currently uses, or Add existing… for another mod folder. Registering a collection does not move or delete mods.

4. Inspect the collection

Search the inventory, review versions/authors/install format and double-click a mod for Mod Details and verified source information.

5. Check the savegame

Open Savegames, select the career and review the mod requirements recorded by that save.

6. Create a launch profile

A profile associates a savegame with the registered mod collection intended for that career. You can create one from Savegames or Profiles.

7. Launch through the profile

FSM validates the save/profile/mod combination, switches the active mod collection when necessary using guarded configuration writes, then launches FS25.

8. Use Compare when something doesn’t line up

Compare Mod Folder ↔ Mod Folder, Savegame ↔ Savegame or Savegame ↔ Mod Folder to identify missing mods and version differences.

User Guide

The main concepts.

FS25 user-data folder

The Farming Simulator 25 data location containing savegames, settings and the normal mods location. FSM can detect the standard Windows location or use a custom location you select.

Active mod folder

The one mod directory FS25 is configured to use right now. It may be the standard mods directory or a custom modsDirectoryOverride.

Direct FS25 launch

Launch FS25 on Home starts the game using the currently active FS25 configuration. It uses FSM's executable discovery and launch safeguards but does not activate a profile, change the mod folder or require a career savegame.

Registered mod collection

A mod folder known to FSM. Collections may be ACTIVE, READY or MISSING. Registering, browsing, renaming or unregistering a collection does not delete its mod files.

Savegame recorded mod list

A save records the mods it expected at save time. This is not the same thing as every file currently present in a mod folder, which is why Savegame ↔ Mod Folder comparison is useful.

Launch profile

A profile ties together a named career and its intended registered mod collection. Activating or launching the profile can make sure the correct collection is active before FS25 starts.

Mod Details & source checks

FSM reads local metadata and can store explicit verified source associations for GitHub, ModHub or another trusted project page. Version checks are informational in Beta 0.1; FSM does not automatically replace or install mod files.

Settings & launcher recovery

If the FS25 executable cannot be found automatically, use Settings to browse to it manually. Global launch arguments are passed through unchanged.

Log Monitor

Follow the FS25 log, FSM application log or another text log while reproducing a problem. Beta 2 also includes visual fixes so Log Monitor controls follow the application theme consistently.

Safety

Read first. Write carefully.

Beta 0.1 treats savegames and installed mods as read-only. Write-capable profile/mod-folder activation changes the FS25 mod-directory configuration in gameSettings.xml using backup, staging, validation, replacement and recovery logic.

Keep your own backups. FSM’s guarded writes are not a replacement for independent backups of important saves, settings and unusual custom mod-folder arrangements.

Troubleshooting

Start with environment sanity.

  • Use Home → Refresh after changing FS25 files outside FSM.
  • Confirm the user-data folder and active mods directory are correct.
  • Use Compare when a save and mod collection disagree.
  • Use Log Monitor while reproducing launch/discovery problems.
  • If a registered collection is MISSING, restore its path or edit profiles that depend on it.

The current Community Preview binaries are not Authenticode-signed, so Microsoft Defender SmartScreen may identify the publisher as Unknown publisher.

Support

Export diagnostics deliberately.

Use About Farm Sim Manager → Export support bundle when diagnostic data will help with a bug report. The bundle is created locally and is not uploaded automatically.

Review the ZIP before sharing it. FSM attempts to remove common identifying account/computer details, but user-selected paths, profile names and collection names can still contain personal information.
