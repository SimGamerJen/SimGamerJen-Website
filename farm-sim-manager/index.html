What Beta 0.1 can do.

Farm Sim Manager is conservative by design: read first, validate before writing, and keep recovery possible.

FS25 environment discoveryDetect user-data locations, gameSettings.xml, savegames and custom active mod-directory overrides.
Mod inventory & metadataInspect ZIP and unpacked development mods, versions, authors, icons and verified source associations.
Savegame inspectionRead detected careers and the mod requirements recorded by each save without modifying the save itself.
Comparison toolsMod Folder ↔ Mod Folder, Savegame ↔ Savegame and Savegame ↔ Mod Folder analysis with CSV export.
Managed launch profilesBind a career to a registered mod collection and validate the combination before FS25 starts.
Diagnostics & supportMonitor FSM/FS25 logs and create a locally generated support bundle for troubleshooting.

What comes next

New Career remains the flagship direction.

The Community Preview deliberately stops short of production save generation. The longer-term design is for Farm Sim Manager to prepare a new career before the first in-game load, with a lightweight FS25 bridge applying first-run setup and Crop Control Override remaining authoritative for ongoing crop policy.

The application source, internal architecture and development history remain private. The website publishes only the material users need: release packages, user documentation, release notes and support information.
