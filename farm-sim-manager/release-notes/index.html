Release notes

0.1.0-beta.2
Community Preview.

The second Community Preview adds direct FS25 launching and a set of tester-facing quality-of-life improvements while retaining the launcher, mod, save and profile foundation from Beta 1.

New in Beta 2

What changed.

  • Launch FS25 directly from Home using the currently active configuration and mod folder, without requiring a managed save/profile.
  • Profile save slots now sort numerically as 1, 2, 3 … 10.
  • Main-window and Log Monitor size, position and maximised state are remembered independently.
  • Window placement recovery is safer after monitor, resolution or display-layout changes.
  • Log Monitor Source and checkbox controls now follow the Farm Sim Manager dark theme correctly.
  • Buy me a coffee links are available from the sidebar and About dialog.
  • Community Preview documentation and public support guidance have been expanded.

Direct launch

Play without building a profile first.

The new Launch FS25 action starts Farming Simulator 25 with whatever mod folder is already active. It uses the existing executable discovery, launch arguments, duplicate-process protection and launch-state reporting, but does not switch mod folders or require a career savegame.

Managed profiles remain available when you want Farm Sim Manager to bind a specific savegame to a specific registered mod collection and activate that configuration before launch.

Updating

Moving from Beta 1.

The Beta 2 installer can be installed over an existing Beta 1 installation. Farm Sim Manager user configuration is stored separately from the installed application files, so registered mod collections, profiles and other FSM settings should remain available after the upgrade.

For portable use, extract Beta 2 into its own folder rather than overwriting an older portable installation.

Not yet

Still outside Beta 0.1.

  • Production New Career/save generation.
  • First-run CCO/bootstrap integration.
  • Automatic mod download/update/install.
  • Commercial updater/licensing infrastructure.
Important beta warning: back up important FS25 savegames, settings and custom mod-folder configuration before testing. Current binaries are not Authenticode-signed and may trigger SmartScreen “Unknown publisher” warnings.
