Bug reports

A few details save a lot of guesswork.

The GitHub bug form prompts for the important information, but these are the details worth checking before you submit.

Exact Farm Sim Manager versionUse the version shown in About Farm Sim Manager.
Installer or portableTell us which Community Preview package you are running.
Windows and FS25 contextInclude Windows version and FS25 platform/distribution where relevant.
Steps, expected, actualExplain how to reproduce the issue and what happened instead.
Safe screenshots or error textImages and exact messages are useful when they do not expose private information.
ReproducibilitySay whether it happens every time, intermittently or only with a particular save/mod collection.

Diagnostics

Support bundles are useful. Public uploads are not always safe.

Farm Sim Manager can create a support bundle from About Farm Sim Manager → Export support bundle.

Review before sharing.

A support bundle can contain local filesystem paths, usernames, profile names, collection names and other information that may identify your setup. Do not upload an unreviewed bundle, full log archive, credentials or other sensitive material to a public GitHub issue.

If a bundle is needed, open the public issue first and state that you can provide diagnostics privately when requested. Then use the private contact route and include the GitHub issue number so the material can be matched to the report.

Community Preview

Testing software, not your only copy of the farm.

Farm Sim Manager is still pre-release software. Keep independent backups of important FS25 saves, settings and custom mod-folder configuration before testing.

SmartScreen is expected on current builds. The Community Preview binaries are not yet Authenticode-signed, so Microsoft Defender SmartScreen may report an unknown publisher. Only use packages downloaded from the official Farm Sim Manager page on simgamerjen.com.
