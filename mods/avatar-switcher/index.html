ASAVATAR SWITCHER

What it does

Keep the character. Change the player.

AvatarSwitcher turns the FS25 wardrobe into a reusable preset system. Save a configured appearance once, give it a recognisable identity, then apply it again from the in-game selector whenever a save or role calls for it.

Reusable presetsSave the current wardrobe appearance with a unique preset ID, display name and category.
In-game selectorBrowse, filter, apply and delete saved appearances without leaving the game.
Wardrobe integrationSave directly from the Farming Simulator wardrobe using the dedicated AvatarSwitcher control.
Persistent storagePresets live under modSettings so they survive mod updates and remain available across sessions.
Integration APIExposes a public API for companion mods such as HelperProfiles to resolve and use saved appearances.
