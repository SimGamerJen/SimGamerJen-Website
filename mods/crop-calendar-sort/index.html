CCSCROP CALENDAR SORT

What it does

Put the calendar in an order that helps.

Crop Calendar Sort adds a SORT action to the standard Farming Simulator 25 crop calendar. Choose a sorting mode through the stock FS25 option dialog and the calendar is reordered immediately.

Reference sortsNative Order, Alphabetical A-Z, Plantable A-Z, Planting Start and Harvest Start.
Gameplay sortsPlant Now, Harvest Now, Next Planting and Next Harvest use the current seasonal period to bring the most relevant crops forward.
Presentation onlyThe mod changes display order only. It does not alter crop definitions, seasonal windows, growth states, fields, contracts or savegame crop data.
Persistent preferenceYour selected sorting mode is stored as a player UI preference under the mod settings folder rather than as savegame state.
Integration APICropCalendarSortAPI v1 allows another mod to reuse the sorting engine deliberately instead of competing with the native-calendar hook.
