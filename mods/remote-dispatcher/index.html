RDREMOTE DISPATCHER

What it does

Set the job up, step away, then send it.

Remote Dispatcher adds a control layer above AutoDrive and Courseplay. Prepare the route or fieldwork job normally, retain a target vehicle, move the player or camera where you want it and dispatch the vehicle without climbing back into the cab.

Remote start / stopTrigger the retained vehicle's prepared AutoDrive or Courseplay task without entering the vehicle.
Cinematic selectorUse a lightweight in-game HUD to choose the live target separately from the management screen.
Per-vehicle setupChoose the automation provider and, with HelperProfiles, assign a named worker to each configured vehicle.
Persistent dispatchProvider, worker assignment and retained target are stored per save using the vehicle's FS25 unique ID.
Named-worker safeguardsHelperProfiles integration fails closed when the assigned worker is missing, off roster or already active instead of silently substituting someone else.
Distant vehicle wakeKeeps a remotely dispatched vehicle active long enough for AutoDrive or Courseplay to begin away from player proximity.

The current public alpha is single-player only and is supported with HelperProfiles 2.1.1.0. AutoDrive and/or Courseplay are required for the corresponding automation functions.

Remote Dispatcher does not create AutoDrive destinations or Courseplay jobs; the task must already be prepared before remote dispatch.
