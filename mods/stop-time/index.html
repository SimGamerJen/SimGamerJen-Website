0STOP TIME

What it does

Stop the clock without changing the plan.

StopTime is deliberately lightweight: press 0 to stop the game clock, press it again to resume, and the mod restores the exact time scale that was active beforehand.

Exact stopSets the in-game time scale to exactly 0 rather than slowing it to a near-stop.
Resume correctlyRestores the previously active time scale when the clock starts again.
Vehicle supportThe control works both on foot and while operating a vehicle.
Multiplayer awareSupports hosted multiplayer and dedicated servers, with control restricted to the host or logged-in server administrator.
Clear feedbackShows an independent green upper-right status message for four seconds when the state changes.
